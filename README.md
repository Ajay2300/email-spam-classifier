# Email Spam Classification using Logistic Regression

This project classifies emails as spam or ham using Natural Language Processing (NLP) techniques.

## Dataset
- Email text dataset
- Labels: Spam / Ham

## Approach
- Text preprocessing
- TF-IDF Vectorization
- Logistic Regression classifier

## Results
- Accuracy: **96%**

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Jupyter Notebook

## How to Run
1. Install dependencies
2. Run `spam_classifier.ipynb`
